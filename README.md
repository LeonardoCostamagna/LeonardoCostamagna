<h2>📚 Recommended Reading</h2>

A curated list of books that have shaped my engineering and development journey:

* 📖 **"Introduction to Embedded Systems - A Cyber-Physical Systems Approach"** – E. A. Lee and S. A. Seshia
* 📖 **"Making Embedded Systems - Design Patterns for Great Software"** – Elecia White
* 📖 **"Design Patterns for Embedded Systems in C - An Embedded Software Engineering Toolkit"** – Bruce Powel Douglass
* 📖 **"Mastering the FreeRTOS™ Real Time Kernel - A Hands-On Tutorial Guide"** – Richard Barry
* 📖 **"Reusable Firmware Development - A Practical Approach to APIs, HALs and Drivers"** – Jacob Beningo
* 📖 **"The C Programming Language - Based on ANSI C"** – Brian W. Kernighan and Dennis M. Ritchie
* 📖 **"C/C++ and Java: How to Program"** – Harvey M. Deitel and Paul J. Deitel
* 📖 **"The Linux Command Line"** – William Shotts
* 📖 **"Mastering Embedded Linux Programming"** – Frank Vasquez and Chris Simmonds
